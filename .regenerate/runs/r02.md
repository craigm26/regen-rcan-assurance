## What this run taught
The second build passed everything that mattered, and the run still failed twice, both times
outside the spec. The container restarted under it, which led to finding that the builder had
inherited the orchestrator's environment, and the suite's dependency scan mistook a regular
expression in the builder's own import test for an import. The one spec change came from a
question both builds asked independently: whether "a number" in replay includes infinity. Both
answered it the same way, so the spec was not wrong, but a question asked twice is a sentence
missing.
