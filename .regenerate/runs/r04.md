## What this run taught
The Python build was clean on the first try, on the same tag as the clean TypeScript build. Its
notes list exactly the traps the earlier Python port fell into: Python's `json` accepts `NaN`
and `Infinity`, keeps integers exact, and sorts names by code point. This build avoided all
three because the spec names them (REQ-IF-006, REQ-CJ-001, D-019). It also chose exact rational
arithmetic for the polygon test where the TypeScript builds used floating point. The spec
leaves that choice open, and the suite cannot tell them apart.
